Privacy Policy

Last updated: 25 October 2026

"Secret Smart Stuff uploader" is a private tool used only by the owner of the Secret Smart Stuff YouTube channel to upload the channel's own videos and read the channel's own analytics.

What data it uses

  • It accesses only the owner's own YouTube channel, through Google's official YouTube APIs, with the owner's permission.
  • It uploads videos created for the channel and reads the channel's performance statistics.
  • It does not collect, store, sell or share any data about other people or viewers.

Storage and security

Access credentials are stored as encrypted secrets and are used only to perform the uploads and analytics reads described above.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
