Privacy Policy

Bhaukaali Toons uploader · Last updated: 26 October 2026

Who we are

"Bhaukaali Toons uploader" is a private tool run by the owner of the YouTube channel Bhaukaali Toons (@BhaukaaliToons). It is used only by the channel owner, for the channel owner's own account. It is not a public service.

What Google data the tool uses

When the channel owner signs in with Google, the tool asks for these permissions:

  • Upload videos (youtube.upload) — to upload the channel's own videos.
  • View the YouTube account (youtube.readonly) — to confirm which channel it is uploading to and check upload status.
  • View YouTube Analytics (yt-analytics.readonly) — to read the channel's own performance numbers, such as views and watch time.

How the data is used

  • Only to upload and manage the channel owner's own videos and to read the channel's own statistics.
  • The data is never sold, shared with third parties, used for advertising, or used to train AI models.
  • Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements, and the YouTube API Services Terms of Service.

How the data is stored

  • The sign-in token is stored as an encrypted secret in the owner's private automation account. It is never published.
  • Channel statistics are kept in the owner's private project files for reporting only.

YouTube and Google

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Stored data is deleted on request.
