# Archive: Bhaukaali Toons / "Sab Theek Hai" (26–28 Oct 2026, dropped)

A Hindi/Hinglish 2D cartoon sketch show on the channel Bhaukaali Toons (@bhaukaalitoons, bhaukaalitoons@gmail.com).
The owner dropped it on 28 Oct 2026: genuinely funny comedy proved too hard and too expensive to iterate, while
the Secret Smart Stuff explainer had already shown promise at a fraction of the cost.

- Code (writers' room, independent judge, gates, puppet engine, art growth, sketch assembler): git branch
  `archive/bhaukaali-toons`.
- Lessons that carry over to Secret Smart Stuff: `docs/LESSONS.md`.
- Data (uploads, analytics, owner notes): `*_bhaukaali` tables in the state database.

Nothing here is used by the live pipeline.
