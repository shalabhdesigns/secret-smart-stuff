## Format (unchanged parts)
- 2D cartoon sketch, vertical 1080×1920, 30 fps, about 55 s (48–60 s).
- Locked character library (`creative/puppet/README.md`).
- Burned-in Roman Hinglish captions, coloured per speaker.
- Loops from the last shot to the first.
- Private upload with a scheduled slot after the owner approves (7:30 PM IST).
