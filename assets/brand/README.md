# Secret Smart Stuff brand (29 Oct 2026)

- **Logo:** "Pull Tab", the ring-pull from a drinks can (concept 6 of the 29 Oct exploration; chosen by the owner
  "for now"). Concept by Claude; the final drawing should be refined by a human designer or the owner before any
  copyright/trademark filing (purely AI-made artwork generally can't get copyright in the US). Run a trademark
  clearance search (USPTO, IP India, WIPO; class 41) before registering.
- **Colours:** ultramarine `#1F3BFF`, blush `#FFD6E0`, white `#FFFFFF`. Flat, no gradients.
  Avoid the "AI default" looks: cream + clay/orange + navy, indigo/purple gradients.
- **Type:** Archivo (Bold / ExtraBold / Black; OFL). Logo wordmark set in Archivo Black.
- **Files:** `pull-tab-mark-*.svg` (mark), `profile-800.png` (YouTube), `profile-1080.png` (Instagram),
  `youtube-banner-2560x1440.png` (content inside YouTube's 1546×423 safe area), `youtube-banner.svg` (text as paths).
- **In videos:** white captions with the spoken word in blush; rings, arrows, badges and boxes in ultramarine;
  emphasised words in blush with an ultramarine outline (`config/channel.yaml` → `style`).
